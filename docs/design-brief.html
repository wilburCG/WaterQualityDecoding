WaterQualityDecoding

水质解码器 —— 看懂家门口每一条河
上传一份检测数据，看懂家门口的河；免费提问，获得有出处的水知识。
版本 v0.2　|　编制日期 2026-10-08　|　科普类公民科学项目

1项目背景与定位

城市骨干河道治理成效显著，但居民感受最直接的家门口小微水体，仍存在"水清但不透、发绿有异味"等问题。普通人即使拿到水质检测数据，也看不懂指标含义、不知道是否超标。

「水质解码器」是面向公众的水质科普与信息分享平台，把专业检测报告翻译成人人能懂的结论，并以地图汇集众人的实测分享，以智能体免费提供可持续积累的水知识检索问答。

解码

录入或上传检测数据，自动对照国标判定水质类别，逐项通俗解读，生成可分享的"水质体检报告"。

地图

众包河流地图

在地图上分享自家周边河流的实测结果，按水质等级着色，查看同一点位的历史变化。

知识智能体

基于国标与水处理知识库的免费问答与检索，回答强制附出处，新知识可持续审核入库。

3关键功能设计

3.1 报告解码（核心差异化）

  • 多形式输入：手工录入（首期）、Excel / PDF / 报告照片（后续 OCR 自动抽取）
  • 处理流程：数据结构化 → 对照国标评价 → 逐项通俗化解读
  • 输出「水质体检报告」：综合水质类别（Ⅰ–Ⅴ / 劣Ⅴ）、定类因子、逐项指标卡片（数值 vs 限值、是否超标、可能来源与影响）、一句话总结
  • 一键生成竖版分享图片，便于社交传播

3.2 众包河流水质地图

  • 地图点位气泡按水质类别着色，点击查看断面数据；同一点位提供时间轴趋势
  • 数据可信度分级：① 机构实验室检测　② 便携式仪器　③ 家用试剂　④ 主观描述，显著标注
  • 用户上传内容先审后发，后台人工审核通过后才公开上图

3.3 水质知识智能体（免费开放）

  • RAG 知识库：地表水环境质量标准 GB 3838、生活饮用水标准 GB 5749、地下水标准 GB/T 14848 及水处理工艺、家用净水知识
  • 回答强制附出处：无可靠出处的问题不编造答案
  • 知识库可持续扩充：新研究、新标准、地方实践经审核后入库；问答免费开放，辅以成本监控与滥用防护

3.4 科普内容

  • 指标百科：pH、溶解氧、高锰酸盐指数、氨氮、总磷、总氮、水温（首批 7 篇，持续扩充）
  • 净水常识与误区辟谣：自来水工艺、净水器选择、水垢、余氯等

4核心设计原则

① 判定确定性：水质类别由确定性规则引擎计算（指标值 × 国标限值映射，一票否决），大模型只负责"说人话"，绝不参与达标判定。
② 知识可溯源：所有科普结论与问答均引用国标、文献出处；众包数据按检测方式分级，不混淆为官方结论。
③ 公益可负担：核心能力免费开放；重计算能力（OCR、大模型问答）做合理成本控制，但不设置付费墙。

7首个公开案例：同汾泾水质研究

上海浦东一条全长 2.07 公里的小河，上、中、下游三断面监测。由两位青少年公民科学参与者（公开案例中采用"胡同学""程同学"隐名）完成。

案例讲清三个机理：夜间热分层破坏、底泥上浮导致浑浊；氮磷富营养使藻类滋生（水绿），死藻腐烂产生异味；河流 2 公里自净使下游稳定达到 Ⅲ 类。

8建设路线

M1 报告解码

评价引擎 + 手工录入 + 水质体检报告 + 指标百科 + 同汾泾案例（首期，2–3 个工作日）

M2 众包地图

用户体系、地图分享、先审后发后台、分享卡片

M3 知识智能体

RAG 问答、国标知识库、引用溯源、免费开放

M4 / M5

报告 OCR 自动抽取；官方监测数据对照与订阅提醒

合规与隐私：全站固定声明"众包数据为公民科学分享，仅供科普参考，非官方监测结论"；涉及未成年人的案例一律隐名、不出现学校班级信息，图片剔除可识别画面；支持点位坐标模糊处理。
